## Часть 1. Что входит в 0.1.0-alpha

Цель первой версии — рабочая основа, которую можно открыть на телефоне по ссылке GitHub Pages, установить и проверить на территории зоопарка, а также собрать реальные координаты в полевом режиме. Данные — стартовые, наполняются поэтапно.

| Блок | Состав |
|---|---|
| Каркас | Шапка (логотип, язык, поиск), нижнее меню из 4 пунктов (Карта, Коллекция, Правила, Ещё). Единая компоновка на телефоне, планшете и ПК |
| Язык | Стартовый экран выбора языка (kz / ru / en), переключатель в шапке, сохранение выбора |
| Карта | Leaflet локально, OSM-подложка, ограничение области с запасом под парковку и остановки, контур зоопарка, маркеры по типам, фильтры «Все / Животные / Инфраструктура», «Где я?», попапы, при открытии — вся территория |
| Навигация | «Найти рядом» (аккордеон: Туалет · Кафе · Медпункт · Выход), «К выходу» — линия, расстояние, направление; расстояние в попапах |
| Поиск | Глобальный, по трём языкам сразу, частичные совпадения, без учёта ё/е, і/и, ү/у |
| Коллекция | Разделы по зонам заказчика (группы животных, локации, крупные вольеры, павильоны), поиск, «Показать на карте» |
| Правила | Краткий список с иконками, полный текст (раскрывающийся), предупреждение о выводе без возврата стоимости билета. Текст — временный до получения проекта |
| Ещё | О зоопарке (факты + Волонтёрство, Зоошкола, Экскурсии), Помощь и контакты (места под телефон, WhatsApp, соцсети; «Если потерялся ребёнок» → охрана), Как добраться (к центральному входу по координатам; автобус № 60 через парк культуры; парковка с предупреждением), «Установить приложение», номер версии |
| Часы и санитарные дни | Летний/зимний режим автоматически по датам (временные даты), собственные часы павильонов (Экзотариум 10:00–18:00), санитарные дни, плашка «Сегодня закрыт» |
| Офлайн и обновление | Service Worker по образцу SLDT: каркас + ресурсы + кэш тайлов; автообновление при открытии |
| Сервисная панель | 7 тапов по версии + ключ (PBKDF2, временно `12345`); диагностика, подмена даты и GPS, сброс языка, кэш, журнал ошибок; полевой режим: точки, контуры, треки, спутниковый слой, экспорт GeoJSON с датой и временем |
| Логотип и иконки | Логотип из исходника Corel; иконки маркеров, интерфейса, правил и приложения — **только после утверждения по листу-образцу** |
| Данные | data.json: места (`places`) и обитатели (`animals`), инфраструктура для посетителей; ориентировочные координаты с `approx: true` |
| Тесты | Service Worker (песочница Node), проверка data.json, совпадение версий |

**Следующим блоком (предложено 0.1.x сразу после 0.1.0):** Google Таблица + Apps Script + админпанель (редактор / админ) с предпросмотром: контакты и соцсети, сообщения и акции, мероприятия, кормления, часы и даты сезонов, санитарные дни, временные закрытия, экстренное объявление (только админ). Единый блок «Когда показывать».

**Позже (backlog в CLAUDE.md):** служебный режим (служебные объекты, зоны/квадраты для охраны, заметки с геолокацией, статистика), дорожки и маршрут «К выходу» по дорожкам, экспозиционные маршруты, анимированная заставка, собственные тайлы.
