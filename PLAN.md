# PLAN.md — итоговый план версии 0.1.0-alpha

Статус: **выполнено** (код написан по команде 10.11.2026, проверен; отправка на GitHub — по отдельной команде).
Все решения подробно — в `CLAUDE.md`. Здесь — что именно будет сделано в 0.1.0, в каком порядке и как проверяется.

---

## 1. Цель версии

Рабочая основа путеводителя, которую заказчик:
- открывает на телефоне по ссылке GitHub Pages и устанавливает на экран;
- проверяет на территории зоопарка (карта, «Где я?», «Найти рядом», «К выходу»);
- использует для **сбора реальных координат** в полевом режиме.

Данные стартовые: места и координаты ориентировочные (`approx: true`), пиктограммы животных и знаки правил — временные (пурпурное кольцо).

## 2. Состав версии

### 2.1. Каркас и оформление
- Шапка: логотип, переключатель KZ / RU / EN, поиск.
- Нижнее меню: **Карта · Коллекция · Правила · Ещё**.
- Единая компоновка на телефоне, планшете и ПК (на широком экране просто растягивается).
- Шрифт **Nunito** (400, 700; latin, cyrillic, cyrillic-ext) — файлами в `fonts/`, без внешних сервисов.
- Только светлая тема, палитра из CLAUDE.md. Размеры в относительных единицах (учитывается системный размер шрифта).
- Иконка приложения — вариант Б (белый логотип на салатовом), favicon — «O»-рог.
- Нативный сплэш PWA, без анимированной заставки.

### 2.2. Язык
- При первом запуске — экран с тремя крупными кнопками «Қазақша / Русский / English», язык устройства подсвечен.
- Выбор сохраняется; переключатель в шапке всегда доступен.
- Все тексты интерфейса и данных — на трёх языках. Казахские — черновые, на проверку.

### 2.3. Карта
- Leaflet локально (`lib/`), подложка OSM с кэшированием просмотренных тайлов.
- Ограничение области территорией с запасом (парковка, остановки), минимальный зум ~16; при открытии — вся территория.
- Векторные слои из data.json: контур зоопарка, контуры павильонов и вольерных комплексов (где есть), маркеры в стиле А.
- Подписи крупных мест на карте; мелкие объекты появляются при приближении.
- Фильтры: **Все / Животные / Инфраструктура**.
- Попап места: название, краткое описание, собственные часы (если есть), санитарный день / «Сегодня закрыт», расстояние и время пешком, кнопка «В коллекцию».
- **«Где я?»** — синяя точка, точность; вне территории — «Вы вне территории зоопарка» + «К зоопарку».
- **«Найти рядом»** — аккордеон: Туалет · Кафе · Медпункт · Выход → ближайший объект, расстояние.
- **«К выходу»** (этап 1) — линия до центрального входа, расстояние, стрелка-направление.
- Кнопка «Вернуться к зоопарку», если карту утащили в сторону.

### 2.4. Поиск
- Глобальный, по трём языкам сразу, частичные совпадения, без учёта регистра и пар ё/е, і/и, ү/у и т.п.
- Результаты: «Животные» / «Объекты»; выбор → карта с центрированием и попапом.

### 2.5. Коллекция
- Разделы по зонам заказчика: группы животных, локации, крупные вольеры, павильоны.
- Пиктограммы — временные, с тонким пурпурным кольцом.
- Поиск по списку, «Показать на карте» (переключает вкладку, маркер пульсирует).
- Пометки: санитарный день, «Сегодня закрыт», собственные часы павильона.

### 2.6. Правила
- Краткий список запретов со знаками (временные, с пометкой) + «Дети под присмотром».
- Полный текст — раскрывающийся блок. **Временный текст** на основе правил с сайта до получения проекта.
- Явное предупреждение: за нарушение правил посетитель может быть выведен без возврата стоимости билета.

### 2.7. Ещё
- **О зоопарке:** 1937, 21 га, 380+ видов, ~80 в Красной книге; Волонтёрство, Зоошкола, Экскурсии (1–2 строки + ссылка на сайт); ссылка на сайт и цены.
- **Помощь и контакты:** места под актуальный телефон, WhatsApp, соцсети (пока пустые — скрываются); email; медпункт «Показать на карте»; блок «Если потерялся ребёнок» → охрана.
- **Как добраться:** адрес; кнопки 2GIS / Google Maps / Яндекс — **по координатам центрального входа**; автобус № 60 и рекомендуемый путь через парк культуры; парковка с предупреждением «в сезон часто нет мест».
- **Часы работы:** автоматически лето/зима по датам (временные даты в data.json), без выходных.
- «Установить приложение» (на iPhone — короткая инструкция «Поделиться → На экран „Домой“»).
- Номер версии внизу — **7 тапов за 3 с → вход в сервисную панель**.

### 2.8. Офлайн и обновление (по образцу SLDT)
- `sw.js`: кэш каркаса `app-<версия>`, кэш ресурсов `assets-<версия>` (шрифты, иконки, докачка в фоне), **кэш тайлов** с ограничением размера.
- Страница «сначала сеть» с таймаутом 3,5 с, остальное «сначала кэш».
- Автообновление при открытии: `updateViaCache: 'none'`, `skipWaiting` + `clients.claim`, одна перезагрузка; проверка и при возврате в приложение.
- Отложенная перезагрузка, пока идёт запись трека в полевом режиме.
- Все пути относительные (переезд на almatyzoo.kz без правок).

### 2.9. Сервисная панель (маркеры кода `ZOO:SYS-TOOLS:START/END`)
- Вход: 7 тапов по версии → ключ (PBKDF2, соль + хэш, временный пароль `12345`). Тап по фону окно не закрывает.
- Диагностика: версия приложения и данных, состояние Service Worker и кэшей, размер кэша тайлов, «Очистить кэш и перезагрузить».
- GPS: текущие координаты и точность.
- Подмена даты и местоположения (для проверки сезонов, санитарных дней, «вне территории»).
- Сброс языка (снова экран выбора).
- Подсветка мест с `approx: true`; **список заглушек** (пиктограммы животных и знаки правил).
- Журнал ошибок с кнопкой «Отправить» (текстом).
- **Полевой режим:** спутниковый слой; точка «Я стою здесь» (10 с усреднения GPS, точность) или тап по карте; контуры; **треки** с удержанием экрана; название и тип; правка и удаление; хранение в localStorage; **«Экспорт»** — GeoJSON с датой и временем в имени (`zoo-points_ГГГГ-ММ-ДД_ЧЧ-ММ.geojson`) через «Поделиться».

## 3. Данные — `data.json`

```
meta        — версия данных, границы карты, центр, координаты центрального входа
settings    — сезоны (временные даты), часы зоопарка и касс по сезонам, санитарные дни
zones       — разделы коллекции (id, тип: группа / локация / вольер / павильон, названия kz/ru/en)
places      — места на карте: id, zoneId, type (animal / infra), category, icon,
              lat/lng или контур, approx, hours (необязательно), sanitaryDay,
              title/description kz/ru/en, visibility: public (служебный слой — позже)
animals     — обитатели: id, placeId, title kz/ru/en (в 0.1.0 — по одному на крупный вольер)
icons       — реестр пиктограмм: id → файл, placeholder: true/false
rules       — краткие запреты (иконка + текст) и полный текст, kz/ru/en
info        — тексты «О зоопарке», «Помощь», «Как добраться», программы, ссылки
contacts    — телефон, WhatsApp, соцсети, email (пустые поля скрываются)
ui          — все строки интерфейса kz/ru/en
```

Структура закладывается так, чтобы позже без переделки добавлялись: полная коллекция, служебный слой, оперативные данные из Google Таблицы (модуль «источник данных»).

## 5. Проверка перед отправкой

**Слой 1 — автотесты (Node + jsdom), по одному набору:**

| schedule | лето/зима, часы касс, часы Экзотариума, санитарные дни, «Сегодня закрыт» — с подменой часов |

## 6. Порядок работы после команды

1. Скачать из npm нужное для сборки: Leaflet (в `lib/`), Nunito (в `fonts/`), jsdom (только для тестов).
2. Каркас, данные, оформление, язык.
3. Карта, поиск, коллекция, правила, «Ещё».
4. Service Worker, manifest, иконки приложения.
5. Сервисная панель и полевой режим.
6. Тесты обоих слоёв, исправления, раздел «Проверено».
7. Показать заказчику снимки экранов и отчёт.
8. **По команде:** отправка на GitHub, метка `v0.1.0-alpha`.
9. Инструкция по включению GitHub Pages → заказчик включает → проверка на телефоне по чек-листу.

Промежуточные результаты (снимки экранов) показываются по ходу, чтобы можно было поправить направление до конца работы.

## 7. Не входит в 0.1.0

- Google Таблица и админпанель (предложено — следующей версией 0.1.x).
- Служебный режим (служебные объекты, зоны для охраны, заметки, статистика).
- Дорожки, маршрут «К выходу» по дорожкам, экспозиционные маршруты.
- Анимированная заставка, собственные тайлы.
- Полная коллекция, окончательные пиктограммы животных и знаки правил (по эскизам заказчика).

# План версии 0.1.3-alpha — выполнено 10.11.2026 (+ контур и дорожки OSM, служебные объекты для полевого режима)

1. **Зимние вольеры:** у зоны коллекции летнее и зимнее положение (на месте / экспонируемый зимний вольер / не экспонируется), свои даты перевода; автоматическое переключение; пометки в попапе и коллекции. Данные — позже, до этого все зоны «на месте».
2. **Сезонные объекты:** «работает только летом» — зимой иконка скрыта.
3. **Временные закрытия:** «с — по» + причина на kz/ru/en — иконка скрыта на это время.
4. **«Найти рядом»** пропускает закрытые и сезонно скрытые объекты.
5. **Переключатель «Схема / Спутник»** на карте — в обычном и полевом режиме; выбор запоминается отдельно для каждого режима (по умолчанию схема / спутник).
6. Подмена даты в сервисной панели работает и для перевода в зимние вольеры и закрытий.
7. Тесты: зимние вольеры × даты, сезонные и закрытые объекты, «Найти рядом» мимо закрытых, переключатель подложки; новые проверки должны падать на 0.1.1.

# План версии 0.1.4-alpha — выполнено 10.11.2026

1. **«Коллекция» → «Жануарлар / Животные / Animals»:** вкладка, заголовок, строка поиска, кнопка в попапе.
2. **Путь через парк культуры:** постоянный рекомендуемый путь от центрального входа в ПКиО (43.261270, 76.965365) до центрального входа в зоопарк — линия по дорожкам OSM (855 м, ~11 мин), отметка входа в парк, рамка карты расширена на запад; дорожки парка — из файла OSM.
3. **Служебные дорожки:** в полевом режиме нажатие на дорожку → «Служебная» / «Обычная»; запись в экспорт; у посетителя — серый пунктир и «Проход запрещён»; в data.json — флаг у дорожки.
4. Тесты: новые проверки падают на 0.1.3.

Следом — координаты из полевого режима (места, вход, служебные объекты, недостающие дорожки) — по мере поступления экспорта.
