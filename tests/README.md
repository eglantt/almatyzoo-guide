# Тесты путеводителя

Папка не влияет на работу приложения: Service Worker её не кэширует, интерфейс её не использует.

## Слой 1 — автотесты (Node 18+ и jsdom)

```
cd tests
npm install
npm test               # все наборы по очереди
node run.js sw app     # только указанные
```

Для набора `fonts` нужен Python 3 с `fonttools` и `brotli` (`pip install fonttools brotli`): так читается таблица символов прямо из файлов шрифта.

| Набор | Что проверяет |
|---|---|
| data | data.json: три языка, уникальные id, связи место → зона, пиктограммы в реестре и спрайте, координаты в границах и в контуре, часы и сезоны, все ключи интерфейса из кода есть в данных |
| version | версия совпадает в app.js, sw.js, data.json, CHANGELOG; каркас SW содержит всё, на что ссылается index.html |
| fonts | каждый символ приложения есть в файлах Nunito; казахские буквы; нет внешних сервисов шрифтов |
| app | настоящий index.html на kz / ru / en: запуск, выбор языка, меню, фильтры, поиск, связи карта ↔ коллекция, правила, «Ещё», пурпурные кольца заглушек |
| schedule | лето/зима и их границы, часы касс и Экзотариума, санитарные дни × сезоны, плашки «закрыто» — с подменой часов |
| geo | расстояния и направления, «Где я?» внутри/снаружи/без разрешения/без GPS, «Найти рядом», «К выходу», расстояние в попапе |
| panel | 7 тапов за 3 с, ключ, подмены даты и GPS, сброс языка, полевой режим (точка, контур, список, удаление, имя файла), недоступность без ключа |
| sw | Service Worker в песочнице `vm`: каркас, 404, активация, сеть / офлайн / таймаут 3,5 с, докачка, тайлы и их предел, исключённые папки |

Каждый сценарий начинается с чистого запуска страницы. Наборы запускаются по одному: часть проверок зависит от времени.

## Слой 2 — Chromium (Playwright)

```
python3 -m http.server 8765        # в корне проекта
node tests/visual.js <папка-для-снимков>
```

Снимки 360 / 393 / 1280 × kz / ru / en для экранов «Карта», «Коллекция», «Правила», «Ещё»; проверка горизонтальной прокрутки, обрезанных подписей и загрузки шрифта. Часы зафиксированы, анимации выключены, тайлы карты не грузятся.

## Правила

- Новая проверка должна падать на версии с ошибкой; проверки «вхолостую» не допускаются.
- Упавшую старую проверку не ослаблять, пока не ясно — ошибка это или намеренное изменение.
- Итоги — в разделе «Проверено» CHANGELOG.md.
