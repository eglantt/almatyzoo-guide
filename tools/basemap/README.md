# Карта-подложка «Схема» (с 0.1.9)

Приложение рисует «Схему» само, из двух файлов в `map/`. Они собираются здесь.

| Файл | Что в нём | Скрипт |
|---|---|---|
| `map/base.json` | город вокруг зоопарка: кварталы, зелень, вода, дороги, тропинки, ограды, подписи трёх улиц | `build_base.py` |
| `map/topo.json` | внутри ограды — топосъёмка 2019: здания, водоёмы, ограды (сглаженные), подпорные стенки | `build_topo.py` |

Исходные данные — `src/`:
- `osm-area.json` — выгрузка OpenStreetMap (overpass-turbo), © участники OpenStreetMap, лицензия ODbL;
- `topo-inside.json` — слои топосъёмки 2019 г. (ТОО «Smart GIS», М 1:500), привязанные к GPS; снесённое сооружение у хищных птиц исключено. Права — у зоопарка.

`hide.json` — где на схеме убрать ограды топосъёмки (сейчас — у Дома хищников).
`nogreen.json` — где внутри ограды не рисовать зелень OSM (сейчас — у слонов и бегемотов).
`src/topo-bld-lines.json` — исходные линии зданий топосъёмки (из них собираются контуры, 0.1.11).

Отдельные линии оград и стенок убираются без пересборки: номер линии (`id` в `map/topo.json`) — в `data.json` → `basemapHide`. Номера приходят из выгрузки полевого режима («Линии схемы»).

Пересборка (из корня репозитория, нужны Python 3, shapely, numpy, scikit-image):

```
python3 tools/basemap/build_base.py
python3 tools/basemap/build_topo.py
```

Названия улиц на трёх языках — в `data.json` (`ui.street_*`). Цвета и детали по масштабу — в `app.js` (раздел «Своя карта-подложка»).
