# «Вид сверху» (с 0.1.12)

Основная карта посетителя — 2.5D-рендер территории зоопарка по топосъёмке 2019 года: трава, вода, крыши, кроны, тени, дорожки и ограды. Приложение показывает его плитками из `map/top/<версия>/`; за внешней оградой картинка растворяется, дальше видна «Схема» города.

| Шаг | Скрипт | Результат |
|---|---|---|
| 1. Рендер | `render.py [м/пиксель] [PNG]` | `out/topview.png` (RGBA, 0,1 м/px ≈ 5400 × 7500) + `out/topview.json` (кадр). Папка `out/` в git не идёт |
| 2. Плитки | `tiles.py <версия> [PNG]` | `map/top/<версия>/{z}/{x}/{y}.webp` (масштабы 16–20) + `index.json` (список плиток) |

Исходные данные:
- `src/topview-src.json` — полный набор зданий топосъёмки с материалом крыши (195), все ограды из чертежа (1235), граница по внешней ограде, точки деревьев (1928), высотные отметки (1125). Метры от центра `center`. Права на топосъёмку — у зоопарка;
- из приложения: `map/topo.json` (водоёмы, подпорные стенки), `map/base.json` (город OSM), `data.json` (дорожки, `basemapHide`).

Пересборка (из корня репозитория; нужны Python 3, numpy, scipy, shapely, Pillow; ≈ 4 ГБ памяти, ≈ 5 мин рендер + 3 мин плитки):

```
python3 tools/topview/render.py 0.1
python3 tools/topview/tiles.py r2
```

После нарезки новой версии (`r2`, `r3` …):
1. `data.json` → `settings.topView`: `"map/top/r2"`;
2. `sw.js` → `TOP_VERSION = 'r2'` (тест topview Т1i проверяет совпадение);
3. старую папку `map/top/r1` удалить (тест Т1 смотрит только текущую).

Новая версия папки нужна, чтобы телефоны не держали старые плитки: кэш `top-<версия>` прежней сборки удаляется при обновлении.

Изменения на территории (новое здание, снос, ограда) и убранные линии полевого режима попадают в «Вид сверху» только после пересборки.
