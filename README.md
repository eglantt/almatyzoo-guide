# almatyzoo-guide

**Путеводитель по Алматинскому зоопарку** — Progressive Web App (PWA) для посетителей Алматинского зоопарка (Алматы хайуанаттар бағы).

Главная задача — помочь посетителю ориентироваться на территории: карта с вольерами, павильонами и инфраструктурой, коллекция по зонам, правила посещения, контакты и как добраться.

- Языки: казахский, русский, английский
- Работает офлайн после первой загрузки
- Мобильный приоритет: одной рукой, на улице, при ярком солнце
- Чистый HTML / CSS / JS, карта — Leaflet + OpenStreetMap

## Статус

🚧 **В разработке.** Готовится версия `0.1.0-alpha`. Кода приложения пока нет — только документация.
